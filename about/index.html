About this project

Working with atoms is a community project built by Jack Aspinall, a researcher at the University of Oxford, with the aim of creating the most compelling, engaging and effective way to learn materials science.

The content is written to be rigorous but accessible, with interactive visualisations, worked examples and practice problems throughout. The goal is to go far beyond a simple wiki and use the full flexibility of a website to provide the best possible learning experience.

This project is built in a personal capacity and does not represent the views or endorsement of the University of Oxford or any affiliated institution.

Contributing

This is an open project. If you would like to contribute content, suggest corrections, or help build interactive tools, the source code is available on GitHub.

Contact

For questions, suggestions or collaboration, reach out via the GitHub repository.
